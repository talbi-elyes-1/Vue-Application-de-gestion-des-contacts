# Application de gestion des contacts

## Description

Cette application permet de gérer une liste de contacts avec Vue.js.

## Fonctionnalités

* Afficher la liste des contacts.
* Ajouter un nouveau contact.
* Modifier les informations d'un contact.
* Ajouter une photo depuis l'ordinateur.
* Enregistrer les données dans le navigateur avec localStorage.
* Accéder aux fonctions d'appel et d'envoi d'e-mail.

## Technologies utilisées

* Vue.js 3
* Vue Router
* Vite
* JavaScript
* HTML et CSS
* localStorage

## Installation et lancement

Installer les dépendances :

```bash
npm install
```

Lancer le serveur de développement :

```bash
npm run dev
```

Ouvrir ensuite l'adresse affichée dans le terminal.
